Settings

Qwen-Image 2.1 is not distilled: every step evaluates the network once per branch that carries weight — the prompt, the prompt + seamless sentence, and (above prompt strength 1) the negative prompt. Prompt strength 1 is how the model is meant to be sampled and drops the unconditional branch; seamless strength 0 drops the seamless one. Turning seamless off sets the seamless strength to 0 and stops the wrapping; turning it back on restores the strength you had.

A preset fills the fields below from configs/pe/<name>.json; edit them freely afterwards. The run records whatever was sent.

Nearest copy keeps every trained frequency and measures displacements around the torus; attention is written out by hand, about 2× the stock cost. Periodic snaps every plane that makes at least min cycles turns across the image to a whole number of turns (max rel. error, if set, snaps only planes already close to one) and leaves the slower planes as trained, stretched to one turn, or dropped; stock fused attention runs unless text is unanchored. Scope says whether only the output image's tokens get the snapped table or the prompt's too. Unanchored text makes the network blind to where the image was cut.
